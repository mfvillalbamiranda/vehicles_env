# vehicles_env

Asegúrate de actualizar el archivo README cuando hayas terminado. Este debe incluir una breve descripción del proyecto, donde se explique para qué sirve la aplicación web y qué tipo de funcionalidad proporciona.
La página web consta del proyecto para el sprint 7, donde se realiza un análisis explotarotio de una base de datos de vehículos en los Estados Unidos. Se realizan dos tipos de gráficos: un histograma sobre el odómetro y un gráfico de dispersión sobre la relación entre el precio y el año de fabricación del automóvil
